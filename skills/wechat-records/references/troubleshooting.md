# 兼容性与排错

| 情况 | 处理 |
| --- | --- |
| 只有 setup/chats/messages/send，没有 sessions/history | 同名项目冲突；运行本技能 install/cli-help，不使用 PATH 中那个 CLI |
| WorkBuddy 缺失或卸载 | 不影响独立运行环境；需要导入的已有密钥必须仍存在 |
| 没有找到 db_storage | 微信设置查看文件管理目录；doctor --search-root 指定盘上的微信文件根目录，不全盘递归扫描 |
| 多个 Weixin.exe | 用户确认登录账号和目标 PID；只读扫选中进程，并用目标 DB HMAC 复核 |
| 无法读取进程 | 微信与终端权限不一致；用户可在自己的管理员终端运行初始化命令 |
| Config.Cipher 没找到或没有匹配 | 检查登录、进程、账号路径和版本；一次排查后仍失败则如实报告不兼容 |
| 部分数据库缺密钥 | 展示缺失的相对数据库名，说明会影响哪些查询；不要声称全量可用 |
| 旧密钥验证失败 | 保留旧 profile，用户明确要求后重新导入/提取该账号密钥 |
| 解密了仍然 SQL/schema 报错 | 当前固定上游 CLI 未适配目标数据库结构；不能以解密成功承诺查询成功 |
| Profile busy | 同一账号有在途读取/初始化，等待完成后再操作 |
| Windows 中文乱码 | 使用 `python -X utf8`，不要直接依赖终端默认编码 |
| 安装网络失败 | 确认 HTTPS/PyPI/GitHub 网络；可使用用户自己的代理设置，不禁用证书校验 |

本项目没有附带微信安装包，不建议为排错降级正在使用的微信，也不承诺恢复已删除、本地未同步、只有手机端存在的记录。数据读取以电脑端实际落盘内容为准。
